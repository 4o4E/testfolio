# 术语与设计记录

讨论项目、用例、轮次、结果或证据时读取根目录 GLOSSARY.md。讨论行为或架构选择时读取对应 openspec/specs/ 及相关变更的 design.md；历史设计位于 openspec/changes/archive/ 中。

术语只记录业务含义。新含义先取得用户确认再修改 GLOSSARY.md；函数名、实现步骤和技术方案不放入术语表。

设计选择、理由、可行替代方案及限制写入对应变更 design.md 的 Decisions，实际可观察要求写入 specs，执行事项写入 tasks.md。已确认的决定与新请求冲突时，说明具体业务场景并请求用户决定；不静默覆盖。
