# Design

## Context

复用现有 Radix Collapsible、Button 和 Zustand。目录包含递归子目录，收起父目录会卸载子组件；因此展开状态不能仅属于各子组件。

## Decisions

- 现有界面状态中按项目编号及完整目录路径保存展开状态；切换用例时只展开其祖先，不关闭其他目录。与组件内部状态相比，该方式也能保留父目录重新展开后的子目录状态。
- 搜索默认展示匹配目录，但明确的手动或批量选择优先；批量操作覆盖当前筛选结果，隐藏目录状态不变。
- 状态仅保存于当前页面会话，不新增浏览器持久化、接口或数据库字段。
- 使用目录标题旁两个文字按钮，电脑与手机保持相同行为。

## Risks / Trade-offs

- 全部展开长目录会增加可见内容；继续复用侧栏独立滚动，不改变正文高度。
